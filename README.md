# Nyte Client

Nyte Client is a small Fabric mod for Minecraft 1.21 focused on performance and quality-of-life features. It provides a modular framework where features can be toggled in game.

## Building

1. Ensure Java 17+ and Gradle are installed.
2. Run `./gradlew build` to build the mod.

The produced JAR will be located in `build/libs`.
