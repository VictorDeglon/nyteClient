A small, honest set of
client-side tweaks for your server.

Nyte Client is a toggleable Fabric mod — flight, speed, jump tweaks, a smaller hitbox, an ore radar, and a few render conveniences — built for your own server or singleplayer world, controlled from an in-game menu.

Setup

How to install

Standard Fabric mod install — five minutes if you've never done it before.

Install Fabric Loader

Grab the installer from fabricmc.net and run it for Minecraft 1.21.

Download Fabric API

Get the matching Fabric API jar from Modrinth — Nyte Client depends on it.

Download Nyte Client

Use the download button above, or grab a specific version from the releases page.

Drop both jars into your mods folder

Usually %appdata%/.minecraft/mods (Windows) or ~/Library/Application Support/minecraft/mods (macOS).

Launch with the Fabric profile, press Right Shift

That opens the ClickGUI in-game. Click a category, click a module to toggle it.

This is a personal-server toolkit, not an anti-cheat bypass

Every module here is a plain, visible toggle — nothing is built to defeat, spoof, or hide from a server's anti-cheat. The movement modules (Flight, Speed, JumpBoost, AirJump) will get flagged by any server running real movement validation, and that's fine — it's up to the server operator to allow them, not this mod's job to sneak past detection.

Flight specifically needs allow-flight=true in server.properties, or the player needs flight some other way. Without that, vanilla's own anti-fly check will kick you after a few seconds airborne.

Xray is the one module here that isn't a "cheat" in the usual sense — it only reads block data your client already has for loaded chunks, the same way any resource pack or F3 debug screen does. No seed, no server interaction, no wallhack rendering.
